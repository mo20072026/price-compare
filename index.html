计算口径（为什么这样算）
  • 门槛按活动价判定：满减、满减券的门槛一律用折前活动价比，不是减完的价——这是平台真实规则。
  • 同类型券只算一张：店铺券、平台/跨店满减、品类券、直播间券各取最优一张，符合"一单一张店铺券"的限制。
  • 返利是事后返还：一淘 / 联盟 / 多多进宝 按实付乘比例，确认收货后才到账（集分宝 / 佣金），所以计入到手价但不减少当下付款。
  • 返利渠道互斥：一淘、淘宝联盟同属淘客链路，同一订单只能走一条，所以做成单选。
  • 会员成本摊入：月卡 / 年费摊销填了就从到手价里加回去，避免"为了省 20 元办 88 元会员"。
  • 不计入：分期免息、赠品估值、晒单返现（金额不确定），这些不能当降价看。

优惠怎么拿

每个平台的钱藏在哪、入口在哪、哪里会踩坑

通用铁律：叠优惠的正确顺序

  1. 先办卡 — 88VIP / PLUS / 省钱月卡 / SUPER 会员先开通，价格档位和券量都跟着变。
  2. 再领券 — 店铺券 + 平台券（跨店满减）先领进券包，不领就永远不自动减。
  3. 再领红包 — 平台超级红包、直播间红包，通常可与券叠加。
  4. 从返利入口进 — 想拿一淘 / 联盟返利，必须先在返利 App 里搜到同款再进商品页下单；先在淘宝加购再跳过去，很可能丢返利。
  5. 下单时勾抵扣 — 淘金币 / 京豆要在提交订单页手动勾选，默认常常不勾。
  6. 选对支付方式 — 花呗 / 白条 / 银行卡 / 云闪付 立减在支付页才显示，换一张卡可能差几十。
  7. 收货后领返利 — 集分宝 / 佣金在确认收货后结算，别忘了看是否到账。
  8. 买完盯价保 — 京东 7~30 天、淘宝部分商品支持价保，降价了去申请退差。

本工具不抓取任何平台数据，价格与优惠由你手动填写；计算结果为规则推演，实际以平台结算页为准。
